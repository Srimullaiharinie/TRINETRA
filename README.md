\# TRINETRA



\## AI-Based Network Attack Forecasting \& Proactive Cyber Defence



TRINETRA is an AI-based network security prototype that forecasts

the progression of network attacks using temporal network traffic

patterns.



\## Key Features



\- Network traffic feature extraction

\- Temporal sequence modelling

\- GRU-based World Model

\- K-step future attack forecasting

\- Infiltration risk prediction

\- Attack stage mapping

\- Gradient-based feature attribution

\- Defender decision support

\- Offline Streamlit interface



\## Architecture



Network Traffic

→ Feature Extraction

→ Temporal Sequence

→ GRU World Model

→ Future State Prediction

→ Attack Risk Forecast

→ Attack Stage

→ Explainability

→ Defender Decision Support

\## Running the Prototype



Activate the virtual environment:



venv\\Scripts\\activate



Run the Streamlit application:



python -m streamlit run frontend\\app.py



The application runs locally and supports offline inference.
